What it does

One tool. Static posture & live kernel signals.

Container security is split across a dozen Linux interfaces. Cornela folds them into a single command-line surface with explainable findings.

/proc

Host hardening audit

Kernel version, loaded modules, seccomp, AppArmor / SELinux, user namespaces, BPF gates, LSM signals — all in one report.

cg

Container discovery

Groups container-like processes by cgroup with namespace context, effective capabilities, NoNewPrivs, and host-mount risk.

eBPF

Live syscall monitor

Tiny eBPF probes on socket, splice, exec, capability and namespace tracepoints. Verifier-safe, ring buffer to userspace.

seq

Sequence correlation

Doesn't alert on single syscalls. Detects chains like AF_ALG + splice followed by a root UID transition.

CVE

Copy Fail profile

Maps host exposure for CVE-2026-31431: algif_aead availability, AF_ALG access, vulnerable kernel ranges, runtime markers.

{}

JSON & JSONL output

Pipe audit results into CI, log pipelines, or SIEM. Findings include severity, reason, and remediation context.

How it works

Two paths, one correlation engine.

Static checks read Linux state from /proc, cgroups, namespaces and runtime metadata. Live monitoring attaches eBPF probes to syscall tracepoints. Both streams converge in a userspace sequence engine that produces ranked findings.

Install & run

Up and running in one command.

Released binaries for x86_64 and aarch64 Linux. No Rust, Cargo, or source checkout needed. Installer verifies a published SHA-256 checksum before unpacking.

Install

System-wide release install, checksum-verified.

$ curl -fsSL https://raw.githubusercontent.com/chud-lori/cornela/main/scripts/install-release.sh | sh

Host & container audit

Static posture, kernel exposure, container isolation.

$ cornela audit
$ cornela containers

Live eBPF monitor

30-second bounded run with sequence findings.

$ sudo cornela monitor --events --duration 30

Stream to pipelines

JSONL events for SIEM, CI gates, log shippers.

$ sudo cornela monitor --jsonl --max-events 50
CVE-2026-31431

Profile Copy Fail exposure on this host

Summarize kernel ranges, algif_aead availability, AF_ALG accessibility and runtime markers in one command. No exploit code, no kernel modification.

$ cornela cve CVE-2026-31431
$ cornela cve CVE-2026-31431 --json
